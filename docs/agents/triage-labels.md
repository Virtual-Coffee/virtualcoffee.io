# Triage labels

The skills name five triage roles. Four are label names in this repo already; the fifth differs:

| Role in the skills | Label here |
| ------------------ | ---------- |
| `needs-triage`     | `triage`   |

`needs-info`, `ready-for-agent`, `ready-for-human` and `wontfix` are the same string in both. (The issue templates apply `Status: Needs Triage` on their own; `triage` is the label the skills read and write.)
